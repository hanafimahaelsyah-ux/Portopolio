# Kenalan Yuk — Portfolio Personal

## Cara menjalankan
1. Ekstrak folder jika mengunduh ZIP.
2. Simpan `index.html`, `style.css`, dan `script.js` dalam folder yang sama.
3. Klik dua kali `index.html` atau buka file tersebut menggunakan browser.

## Kustomisasi
- Ubah nama, teks, dan bagian minat di `index.html`.
- Ubah warna, ukuran, dan layout di `style.css`.
- Ubah interaksi tema, menu, dan tombol sapaan di `script.js`.

Font Google Fonts membutuhkan koneksi internet; halaman tetap dapat dibuka tanpa font tersebut.
